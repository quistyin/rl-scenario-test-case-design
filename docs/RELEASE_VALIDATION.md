## 操作

```bash
python scripts/verify_public.py
python -m unittest discover -s tests -v
python -m pytest -q
python scripts/reproduce.py --no-plots
python scripts/replay_experiment.py verify-records
python scripts/replay_experiment.py verify-design
python scripts/replay_experiment.py rerun --workers 4 --output generated/smoke-run
```

pytest需另行安装。生成结果写入ignored的generated目录，不混入原始发布数据。复现输入来自仓库本身；外部仅需安装公开环境依赖。
