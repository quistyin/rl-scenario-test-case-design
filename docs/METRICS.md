# 数据与评价口径

## 数据结构

`data/combination_metrics.json`包含1200条组合级记录，四种方法各300条。它不包含单步状态、观测、动作、奖励、轨迹或用例配置。

| 字段 | 含义 |
|---|---|
| method | random、combination、reward或risk；reward始终是稿件采用的修正版 |
| design | 五套设计的索引0-4，不是用例编号 |
| model | 固定模型标识11、22、33，分别对应论文模型1、2、3；权重另见artifacts/models |
| seed | 正式验证环境种子172920000-172920019 |
| sc | 前1-30条用例累计状态覆盖率，分母为9个抽象状态 |
| kpc | 前1-30条用例累计关键路径覆盖率，分母为5条路径 |
| auc | 30个累计kpc值的算术平均 |
| complete | 30条内是否完成五条关键路径全覆盖，0或1 |
| tfc | 首次完成五条路径全覆盖的用例位置；未完成为null |
| paths | 前30条用例覆盖到的路径标识集合，不是轨迹序列 |

## 汇总方式

SC@k和KPC@k分别对每种方法的300个组合等权平均。FCR@k为前k条用例内完成五条路径全覆盖的组合比例。AUC是离散均值，不使用梯形积分。KPC@1是每个组合第一条用例的覆盖比例，不是把30条用例各自的覆盖率另行平均。

TFC未完成时不以30、31或0冒充真实首次全覆盖位置。`TFC_completed_mean`仅对完成组合计算，同时必须查看`TFC_distribution`中`>30`的数量。本文方法全部完成，平均位置为5.48条。

## 统计检验

三个基线分别与本文方法比较KPC@5、KPC@10、KPC@30和AUC，共12项。以20个环境种子为配对块，每块等权平均5套设计和3个模型的15条组合记录，不把共享轨迹引用当作独立样本。

块间差值保留12位小数，零差按wilcox规则排除；使用带并列秩的双侧Wilcoxon符号秩精确符号置换分布，并对12项比较统一Holm校正。公开计算与终稿统计核查一致。这里检验的是完整设计流程，不单独识别风险分析、参数选择或排序的因果贡献。

## 状态与路径定义入口

当前论文的状态、路径变体、终局标签和允许绕行定义见`experiment/magent2_experiment/coverage_model.py`。v1.2.0在公开入口`scripts/replay_experiment.py`中另施加严格P4约束：`state_flags`的全部步骤（包括终止步）均不含M2。阶段序列可能因终局M8优先而隐藏同一步M2，故仅依据`state_trace`不足以判定“全过程未发现敌方”。其他路径的匹配条件不变。

依赖集合中同时保留了旧通用模块`path_model.py`，因为其他兼容代码引用它；其中的旧路径常量不是本论文P1-P5的定义。不得用该旧常量替换当前覆盖模型。公开状态记录已支持从标记和阶段序列重新判断状态及关键路径覆盖，但未保存全部原始观测，不能据此独立重判所有观测到状态谓词的映射。

## 重排分析

`data/reordering_plan.json`固定100种零基位置排列，每种方法、设计、模型和环境种子均使用同一组排列。排列最初由NumPy的`default_rng(202609210)`（PCG64）依次生成；复核直接读取完整排列数组，不依赖随机库版本。

对每个组合和排列，依次求已执行用例的路径集合并集，再计算30个累计KPC的算术平均；对每方法300个组合、100种排列等权平均。实现累计整数路径数，最终除以300×100×30×5，避免多次浮点累加。`results/reordering_summary.json`同时保存分数、整数分子和各排列均值，使用严格P4口径。重排只改变结果的分析顺序，不执行新回合，也不改变冻结计划。
