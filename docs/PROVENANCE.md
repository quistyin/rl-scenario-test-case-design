# 来源及公开处理

本公开包来自2026-09-20完成的固定策略风险场景测试设计实验，统计口径对应2026-09-22终稿复核。公开数据为既有实验记录，不用后续运行替换原数据。

## v1.2.0评价口径更新

2026-10-09按包括终止步在内的全过程无M2约束复核P4。公开入口增加严格判定，新增100种固定排列、重排汇总和125条受影响回合的修正清单；已有原始轨迹、回合索引、标定统计、模型、配置、种子与原实验代码不改写。主顺序的1200条累计覆盖曲线及原发布汇总均不变。

`artifacts/episodes.jsonl.gz`和轨迹压缩包内的`covered_paths`仍为历史缓存，用于完整性审计。当前逐例覆盖集合由`scripts/replay_experiment.py verify-records`从状态记录重新判定，不能直接把旧缓存当作严格P4结果。新生成的修正清单保留每条轨迹的原SHA-256，以便关联原始证据。完整说明见`STRICT_P4_UPDATE.md`。

## v1.1.0补充材料

新增3个原始模型、2352回合标定统计输入、正式四方法20套有序用例、403组唯一配置和24180回合正式执行记录及状态轨迹，关联1200个验证组合。候选重复执行共享方式保持原实验设置不变，36000个逻辑用例引用不被描述为36000次不同执行。

模型、标定输入、原冻结证据逐字节保留，哈希见`artifacts/provenance/source_files.json`。正式记录从原JSONL选择原始行，状态轨迹gzip文件逐字节保留在分卷ZIP内。公开执行计划是原冻结清单和奖励修正清单的派生子集，未更换场景、顺序、种子或模型。

包装层`scripts/replay_experiment.py`新增输出隔离、相对路径、文件校验和重算入口；核心原实验模块哈希保持不变。原始冻结清单中未发布的历史文件不被删除或伪造为已发布，公开执行另有完整校验清单。

状态记录不等于逐步完整原始观测。新模型运行属于复现验收，输出与原记录分开，具体数量和一致性见`RELEASE_VALIDATION.md`。

## v1.0.0汇总包处理

- 原实验核心源码按静态导入依赖提取，未改动函数和算法；每个文件的原始相对路径及SHA-256见`source_manifest.json`。
- 新增`scripts/reproduce.py`，读取公开汇总而不是私有目录。指标算法与终稿核查保持一致，精确检验使用整数化并列秩枚举计数。
- 只公开四种最终方法各300条组合记录的白名单字段，去除原记录中与本次公开目的无关的原子场景、步数和诊断字段。旧基线、消融及辅助对照留在作者本地归档，不混入当前方法比较。
- `table5_reference.json`由待投稿稿件表5提取，只含方法与数值，不包含论文全文或作者信息。
- `reference_statistics.json`保留终稿统计协议、块均值及检验结果，去除本机解释器路径和绝对输入路径。
- 环境信息仅保留软件版本和平台，不含本地解释器地址。
- 发布曲线由公开汇总重绘，数据与终稿对应；不是从文稿图像反推，也不是新的环境执行证据。

上述汇总字段筛选不改变SC、KPC、AUC、全覆盖标志、首次全覆盖位置及最终命中路径集合。v1.1.0增加状态记录层复核，但不将其等同于完整原观测的独立审计。
