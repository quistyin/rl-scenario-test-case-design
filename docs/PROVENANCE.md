# 来源及公开处理

本公开包来自2026-09-20完成的固定策略风险场景测试设计实验，统计口径对应2026-09-22终稿复核。公开包不是一次新的实验。

- 原实验核心源码按静态导入依赖提取，未改动函数和算法；每个文件的原始相对路径及SHA-256见`source_manifest.json`。
- 新增`scripts/reproduce.py`，读取公开汇总而不是私有目录。指标算法与终稿核查保持一致，精确检验使用整数化并列秩枚举计数。
- 只公开四种最终方法各300条组合记录的白名单字段，去除原记录中与本次公开目的无关的原子场景、步数和诊断字段。旧基线、消融及辅助对照留在作者本地归档，不混入当前方法比较。
- `table5_reference.json`由待投稿稿件表5提取，只含方法与数值，不包含论文全文或作者信息。
- `reference_statistics.json`保留终稿统计协议、块均值及检验结果，去除本机解释器路径和绝对输入路径。
- 环境信息仅保留软件版本和平台，不含本地解释器地址。
- 发布曲线由公开汇总重绘，数据与终稿对应；不是从文稿图像反推，也不是新的环境执行证据。

文件字段筛选不改变SC、KPC、AUC、全覆盖标志、首次全覆盖位置及最终命中路径集合。公开汇总不能代替未公开原始轨迹的独立审计。
